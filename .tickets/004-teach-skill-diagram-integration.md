# Update teach skill to auto-generate diagrams in lessons

## What to build

Enhance the teach skill so it naturally produces inline SVG diagrams when writing lessons, guided by the visual teaching steering and svg-patterns reference.

## Changes to SKILL.md

Add a "Diagrams in Lessons" section that instructs the agent to:
1. For every architectural/conceptual explanation: produce an inline SVG diagram
2. Place a one-line verbal summary above each diagram (dual coding principle)
3. Use the color vocabulary (blue=primary, green=output, amber=warning, gray=infra)
4. Limit to 5-9 elements per diagram; break complex into multiple
5. Reference `assets/svg-patterns.md` for reusable snippets
6. When `tools/draw-diagram.py` exists, prefer calling it for complex diagrams
7. When D2 is available, use it for sequence/flow diagrams that benefit from auto-layout

## Also update

- The teach skill's "Lessons" section: add a bullet about visual aids
- NOTES.md template: add "Diagram preferences" section

## Acceptance criteria

- [ ] Teach skill SKILL.md mentions diagram creation as part of lesson authoring
- [ ] Next lesson generated by the skill includes at least one inline SVG
- [ ] Diagrams follow the visual teaching steering rules
