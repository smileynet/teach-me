# Spike: prediction quiz (guess before reading)

## Hypothesis

Placing a quiz question BEFORE the explanation (forcing prediction rather than recall) deepens engagement and primes the learner's attention. GDQuest's "Try Answering This" pattern always appears before the answer is revealed, with "Make your best guess" framing to reduce anxiety.

## What to build

1. Add a prediction quiz to lesson 1 — placed before the "Three Layers" section
   - "Before reading on: what information would a query engine need to find the right files?"
2. Style it differently from end-of-lesson quizzes (subtle visual distinction: "🤔 Take a guess" header, softer border)
3. Add to teach skill: 1-2 prediction questions per lesson, placed before explanations

## Baseline

Current quizzes appear at the end of lessons and test recall of material already read. No prediction/priming mechanism exists.

## Compare against

- Does the prediction question make the subsequent explanation more engaging?
- Is the "guess first" framing anxiety-reducing or confusing?
- Does the visual distinction (from end-of-lesson quiz) feel clear?

## Acceptance criteria

- [x] Prediction quiz demonstrated in lesson 1
- [x] Visually distinct from recall quizzes
- [x] Low-stakes framing ("take a guess, no wrong answers")
- [x] Teach skill documents when/where to place prediction questions
- [x] Before/after comparison presented
