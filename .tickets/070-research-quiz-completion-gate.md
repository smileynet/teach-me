# Research: quiz as completion validation

## Question

Should passing a quiz (or scoring above a threshold) automatically mark a topic as complete? Or should it remain a separate signal alongside the manual "mark complete" button?

## What to explore

- Does quiz completion correlate with actual understanding? (SR data can inform this)
- Should "complete" require both: user marks it AND quiz passed?
- What threshold? All questions right? 80%? Any attempt?
- How does this interact with "generate more" questions (067)?
- Should there be a "completed via quiz" badge vs "self-declared complete"?
- UX: nudge ("you haven't taken the quiz yet — consider it?") vs gate ("must pass to mark complete")

## Deliverable

A decision on whether quiz completion should auto-mark or nudge, with the chosen approach documented as an ADR or ticket update.
