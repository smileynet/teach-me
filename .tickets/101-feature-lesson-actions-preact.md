# Convert lesson-actions.js to Preact component

## What to build

The lesson action bar (navigation, quiz link, mark complete) as a Preact component that mounts into lesson pages. Lessons remain static HTML — Preact mounts into a `<div id="lesson-actions">` at the bottom.

## Migration strategy (islands approach)

Lesson HTML body stays static (generated by the teach skill). Only the action bar is a Preact island:

```html
<!-- Static lesson content above -->
<div id="lesson-actions"></div>
<script type="importmap">...</script>
<script type="module">
  import { render } from 'preact';
  import { LessonActions } from '../assets/components/LessonActions.js';
  render(html`<${LessonActions} domain="..." lessonId="..." />`, 
    document.getElementById('lesson-actions'));
</script>
```

## Deliverables

- `assets/components/LessonActions.js` — nav buttons, quiz link, mark complete, next lesson
- Mount point pattern for lesson scaffold
- Data attributes on mount div provide context (domain, lesson-id, map-page URL)

## Acceptance Criteria

- [x] Action bar renders at bottom of lesson pages
- [x] "← Back to map" navigates to map page
- [x] "Next lesson" navigates to next topic (if known)
- [x] "Mark complete" updates status (calls API or writes to localStorage)
- [x] "Quiz" links to quiz page for this topic
- [x] Static lesson content above is unaffected
- [x] Works alongside existing vanilla lesson pages during migration
