# Feature: Customizable fonts and text size

## What to build

User preference controls for typography: font family, font size, and line spacing. Persisted across sessions (localStorage or workspace config). Accessible from the lesson page without leaving it.

## Acceptance criteria

- [ ] User can change font size (at minimum: small, default, large, XL)
- [ ] User can change font family (serif, sans-serif, monospace, or custom)
- [ ] User can adjust line spacing (compact, default, relaxed)
- [ ] Preferences persist across page loads and sessions
- [ ] Controls accessible from any lesson page (settings gear/panel)
- [ ] Changes apply immediately (no page reload)
- [ ] Doesn't break lesson layout, diagrams, or code blocks at any size
