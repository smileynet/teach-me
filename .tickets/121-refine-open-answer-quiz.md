# Review: Refine open-answer quiz question strategy and skill

## What to build

Audit and improve the current open-answer quiz question approach. Today, questions use "explain to a colleague" framing with criteria-based answers. Review whether this strategy is effective, where it falls flat, and how to improve the prompts, answer evaluation, and feedback loop.

Areas to examine:
- Are the prompts too similar across topics? (all "explain to a colleague..." gets repetitive)
- Is the criteria-based answer format clear enough for self-assessment?
- Should there be difficulty tiers (recall → apply → synthesize)?
- How well do the questions test understanding vs just pattern-matching the lesson text?
- What does good open-answer feedback look like when the user responds?
- Should the skill generate different question archetypes (scenario, prediction, debugging, teaching)?

## Acceptance criteria

- [ ] Audit existing questions across all example workspaces for variety and quality
- [ ] Identify patterns that work well and patterns that are repetitive/weak
- [ ] Update the quiz-me skill and SR question generation guidance with refined strategy
- [ ] Define 4-6 distinct question archetypes with examples and when to use each
- [ ] Generated questions use varied framing (not all "explain to a colleague")
- [ ] Criteria answers include clear "must mention" items AND "bonus" stretch items
