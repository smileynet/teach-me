# Page Scaffolds

Templates for each page type. The teach skill reads these before generating content.

## Architecture

All pages use **Preact + HTM + Signals** loaded via vendored ES modules (no CDN, no build step).

- **Import map** in `<head>` resolves bare specifiers to `../assets/vendor/`
- **Data island** (`<script type="application/json" id="page-data">`) carries page-specific data
- **Components** in `../assets/components/` mount into the page as islands
- **CSS variables** from `../assets/style.css` handle theming (dark/light)

## Page Types

| File | Generated by | Interactive components |
|------|-------------|----------------------|
| `lesson.html` | teach skill (manual) | GlossaryQuiz, LessonActions |
| `reference.html` | teach skill (manual) | LessonActions |
| `quiz.html` | `generate-quiz-page.py` | QuizView (full Preact page) |
| `quick-check.html` | `quick-check.py` | ReviewView (full Preact page) |

## Conventions

- Lesson/reference pages: static HTML body + Preact islands (action bar, glossary)
- Quiz/review pages: full Preact apps (Python generates data island, component renders everything)
- Map/index pages: full Preact apps (generated by `generate_map_page.py` / `generate_index_page.py`)

## Adding a Component

1. Create `assets/components/MyComponent.js`
2. Import from `preact`, `@preact/signals`, `htm`
3. Export named function component
4. Use signals from `store.js` for shared state
5. Import in the page's `<script type="module">` block
