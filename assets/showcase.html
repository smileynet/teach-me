.key-concept

After this lesson: You can implement three outline approaches and explain when to use each — inverted hull for per-object control, screen-space for production quality, and JFA for wide outlines.

.note (info / new concept)

New concept — CAMERA_VISIBLE_LAYERS: A shader built-in that exposes which render layers the current camera can see. By checking specific bits, a single shader can branch its behavior per camera.

.note (decision guidance)

When to use which:
  • Inverted hull — characters where you need per-object artistic control.
  • Screen-space — environments where every surface needs outlines.
Default recommendation: Start with screen-space.
