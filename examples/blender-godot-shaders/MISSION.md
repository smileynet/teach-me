# Mission: Blender → Godot Shader Pipeline (Esoteric Ebb Style)

## Why

Building a game with a stylized forest scene/level inspired by the esoteric ebb art style. Need to bridge Blender's shader graph and Godot's shader language to produce assets that look correct after export.

## Success Criteria

- Create textured, stylized environment assets in Blender using shader techniques that support the ebb aesthetic
- Understand which visual effects belong in Blender's material system vs Godot's shader language
- Export assets from Blender to Godot without losing intended visual quality
- Write and modify shaders in both tools to achieve a cohesive stylized forest look
- Compare shader approaches across both tools to make informed pipeline decisions

## Starting Point

- Blender: comfortable with modeling and basic texturing
- Godot: familiar with scenes/nodes/GDScript, minimal shader experience
- Art direction: esoteric ebb — needs research to pin down visual vocabulary

## Constraints

- Game-oriented (real-time performance matters)
- Forest/environment focus (not character art)
- Pipeline must be repeatable (not one-off hero assets)
