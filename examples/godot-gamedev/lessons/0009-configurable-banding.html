Configurable Toon Banding

Lesson 9 · Per-Material Toon Shading (MKToon) · ~10 min read
Win: You can build a configurable banding shader with smoothness, scale, and threshold — and explain why mix(banded, continuous, smoothness) gives soft N-band shading.
After this lesson: You have a shader with five artist-facing sliders that control band count, edge softness, shading intensity, and shadow position — all without touching code. This is the foundation for the entire per-material toon track.

The Problem: Hard Bands Aren't Enough

← Prerequisite: Lesson 4: Toon Banding (the modulo trick)

In Lesson 4 you built toon_bands.gdshader — the modulo trick gives you N evenly-spaced hard bands from a single integer uniform. That's great for bold comic-book shading, but an art director might ask for:

  • Soft transitions between bands (ink-wash, watercolor, subtle illustration)
  • Adjustable intensity — how dramatic the shading appears, from barely-there to high-contrast
  • Shifted split point — more shadow or more light, per-material, without moving the actual light

None of these are possible with the modulo trick alone. You'd need to write three different shaders for three different art styles. What we want is one shader with sliders.

Step 1: From Modulo to Floor-Divide

The modulo trick snaps values UP to the next band boundary. For configurable shading, we'll use the floor-divide approach instead — it snaps DOWN and produces output spanning the full [0, 1] range:

// Band quantization: floor-divide spans full [0,1] range
float banded = floor(centered * light_bands) / max(light_bands - 1.0, 1.0);

Why /(light_bands - 1) instead of /light_bands? With /N, the brightest band tops out at (N-1)/N — never reaching full white. Dividing by (N-1) guarantees the top band hits 1.0, giving you the full brightness range from dark to fully lit.

Floor vs Modulo: The modulo trick from Lesson 4 (x + mod(1.0 - x, cuts_inv)) rounds UP — each pixel shows the next boundary's brightness. Floor-divide (floor(x * N) / (N-1)) rounds DOWN — each pixel shows the current band's floor value. Visually they produce similar steps, but floor-divide gives a cleaner [0, 1] output range that's easier to manipulate with smoothness and scale.

Step 2: The Centering Trick (Threshold Control)

Raw NdotL ranges from -1 (facing away from light) to +1 (facing directly at light). Before quantizing, we remap it so that 0.5 sits at a controllable midpoint:

// Center around threshold (Half Lambert remap)
float centered = NdotL - light_threshold - diffuse_threshold_offset + 0.5;
centered = clamp(centered, 0.0, 1.0);

This is the same principle as Valve's Half Lambert technique: make 0.5 the default boundary between "lit" and "unlit." Now light_threshold becomes an intuitive slider — values above 0.5 push the boundary into the lit region (more shadow), values below 0.5 push it into shadow (more lit). The offset provides a secondary fine-tune.

New concept — centering trick: By subtracting the threshold and adding 0.5, you create a coordinate system where 0.5 is always "the decision point." This means your floor-divide always has the band boundaries distributed symmetrically around your chosen midpoint. Without centering, the threshold slider would work backwards or require mental math.

Step 3: The Smoothness Blend

Here's the key insight that makes this shader flexible. After computing the hard-banded value, we blend it with the original continuous value:

// Smoothness: blend quantized result with continuous value
float lit_factor = mix(banded, centered, diffuse_smoothness);

mix(banded, centered, smoothness) interpolates between two extremes:

  • smoothness = 0.0 → pure banded — hard cel edges, discrete steps
  • smoothness = 1.0 → pure centered — smooth continuous gradient, no quantization at all
  • smoothness = 0.3 → mostly banded with soft transitions — the illustration/anime sweet spot

This is something neither smoothstep() alone nor the modulo trick can do. Smoothstep gives you a soft two-band transition. The modulo trick gives you hard N-band steps. This mix() pattern gives you soft N-band shading — bands are visible but their edges are painterly rather than razor-sharp.

Why not smoothstep between each band? You could compute per-band smoothsteps, but that requires a loop and scales with band count. The mix() approach achieves the same visual result in one operation regardless of how many bands you have — it's the production-friendly shortcut.

Step 4: Scale (How Dramatic)

The final control determines how much contrast the banding creates:

// Scale: how dramatic the shading appears
lit_factor = 0.5 + (lit_factor - 0.5) * light_bands_scale;

This formula expands or compresses the lit_factor around 0.5:

  • scale = 0.0 → everything becomes 0.5 (flat mid-gray, no shading visible)
  • scale = 0.5 → range compressed to [0.25, 0.75] (subtle, understated shading)
  • scale = 1.0 → full [0, 1] range (maximum dark-to-light contrast)

Think of it as a "drama dial." Low values produce the subtle ink-wash look of gouache illustration. High values produce bold comic-book contrast. The band count and positions stay the same — only the visual weight of the shading changes.

The Complete Shader

Putting all four steps together with albedo support and multi-light safety:

shader_type spatial;
render_mode specular_disabled;

// === Albedo ===
uniform vec4 albedo_color : source_color = vec4(1.0);
uniform sampler2D albedo_texture : source_color;
uniform bool use_albedo_texture = false;

// === Toon Banding Controls ===
uniform float light_bands : hint_range(1, 9, 1) = 4.0;
uniform float light_bands_scale : hint_range(0, 1) = 0.5;
uniform float light_threshold : hint_range(0, 1) = 0.5;
uniform float diffuse_threshold_offset : hint_range(-1, 1) = 0.0;
uniform float diffuse_smoothness : hint_range(0, 1) = 0.0;

void fragment() {
    vec3 col = albedo_color.rgb;
    if (use_albedo_texture) {
        col *= texture(albedo_texture, UV).rgb;
    }
    ALBEDO = col;
}

void light() {
    float NdotL = dot(NORMAL, LIGHT);

    // Center around threshold (Half Lambert remap)
    float centered = NdotL - light_threshold - diffuse_threshold_offset + 0.5;
    centered = clamp(centered, 0.0, 1.0);

    // Band quantization: floor-divide spans full [0,1] range
    float banded = floor(centered * light_bands) / max(light_bands - 1.0, 1.0);

    // Smoothness: blend quantized result with continuous value
    float lit_factor = mix(banded, centered, diffuse_smoothness);

    // Scale: how dramatic the shading appears
    lit_factor = 0.5 + (lit_factor - 0.5) * light_bands_scale;

    DIFFUSE_LIGHT = max(DIFFUSE_LIGHT, ALBEDO * LIGHT_COLOR * ATTENUATION * lit_factor);
}
Why specular_disabled? We're writing our own lighting in light(). Godot's built-in PBR specular would add shiny highlights that clash with our toon look. specular_disabled turns off direct-light specular lobes. We'll add our own flat toon specular in Lesson 12.

Check Your Understanding

Exercise: A colleague sets diffuse_smoothness = 1.0 expecting "smooth bands" — softened edges between distinct brightness levels. Instead, they get a plain smooth gradient with no visible banding at all. They ask: "Why doesn't smoothness give me smooth-edged bands? I thought it was supposed to soften the steps."

Explain what smoothness = 1.0 actually does, why it eliminates bands entirely, and what value range would give them the "soft bands" look they want.

Hint

Look at what mix(banded, centered, smoothness) produces at the extremes. What is centered — is it banded, or is it the original continuous value?

Answer

mix(banded, centered, 1.0) returns centered entirely — the pre-quantization continuous value. There are no bands because the floor-divide result is completely ignored. Smoothness doesn't soften band edges; it blends between "quantized output" and "original input." At 1.0, you've blended 100% back to the original.

For soft-edged bands, use values in the 0.1–0.4 range. At 0.2, the floor-divide still dominates (bands clearly visible) but 20% of the continuous signal bleeds through, creating soft transitions between steps. Think of it as "how much of the hard decision to keep" — not "how soft are the edges."
