Specular & Rim Lighting

Lesson 12 · Per-Material Toon Shading (MKToon) · ~11 min read
Win: You can add toon highlights using one reusable threshold-smoothstep pattern applied two ways — and explain why both are additive.
After this lesson: Your shader has flat specular stamps (anime eye-catch lights) and Fresnel rim glow (character separation). Both use the same math — smoothstep(t-e, t+e, x) — with different inputs. Learn the pattern once, apply it everywhere.

The Problem: All Diffuse, No Highlights

← Previous: Lesson 11: Wrapped Lighting & Noise

Your toon shader has beautiful banded diffuse shading with warm/cool colors and organic edges. But it's still purely diffuse — no specular highlights, no edge definition. In cel-shaded art, two highlight effects are nearly universal:

  • Flat specular — a hard-edged white stamp where light reflects toward the camera. The anime "eye-catch light" or the sharp gleam on metallic surfaces.
  • Rim glow — a bright edge where the surface turns away from the camera. Separates characters from backgrounds, especially in dark scenes.

Both effects share one mathematical pattern. We'll learn the pattern once, then apply it twice.

The Threshold-Smoothstep Pattern

This is the most reusable technique in shader programming. Given any value in [0, 1], it produces a controllable hard-or-soft mask:

// THE PATTERN: threshold-smoothstep
// t = threshold (where the cutoff sits)
// e = edge softness (0 = razor-hard, 0.5 = very soft)
// x = input value (any 0-1 scalar)
float mask = smoothstep(t - e, t + e, x);

When x exceeds the threshold t, the mask transitions from 0 to 1. The e parameter controls how wide that transition is:

  • e ≈ 0 → nearly binary (hard step, like step() but anti-aliased)
  • e = 0.1 → slight feathering at the edge
  • e = 0.5 → wide, smooth transition

You'll see this exact pattern in specular highlights, rim lighting, dissolve edges (Lesson 14), outline falloff, and fog boundaries. It's the universal "binary decision with controllable softness" tool.

New concept — threshold-smoothstep: The pattern smoothstep(t-e, t+e, x) creates a soft binary mask from any continuous input. Unlike raw step(), it provides built-in anti-aliasing and artist-tunable edge width. Every hard/soft cutoff in toon shading is this pattern with different inputs and threshold positions.

Flat Specular: The Blinn-Phong Half-Vector

PBR specular uses pow(NdotH, shininess) to create a smooth, physically-based highlight. Toon specular replaces the power curve with our threshold-smoothstep — producing a flat colored stamp instead of a smooth falloff:

// Flat specular (additive): threshold-smoothstep on Blinn-Phong half-vector
if (specular_enabled) {
    vec3 half_dir = normalize(LIGHT + VIEW);
    float NdotH = clamp(dot(NORMAL, half_dir), 0.0, 1.0);
    float spec_threshold = 1.0 - flat_specular_size;
    float spec_edge = max(flat_specular_edge_smoothness, 0.001);
    float spec_mask = smoothstep(spec_threshold - spec_edge, spec_threshold + spec_edge, NdotH);
    toon_color += flat_specular_color.rgb * spec_mask * specular_intensity;
}

The key steps:

  1. Half-vector: normalize(LIGHT + VIEW) — the direction exactly between the light and the camera. When the surface normal aligns with this, you get maximum specular reflection.
  2. NdotH: How aligned the surface is with the half-vector. Values near 1.0 = strong specular, near 0.0 = no specular.
  3. Threshold inversion: 1.0 - flat_specular_size — higher size = lower threshold = more pixels pass = bigger highlight. Think of size as "how much of the NdotH range to include."
  4. Additive: toon_color += — the highlight adds on top of the diffuse toon shading.
Why 1.0 - size? NdotH is highest (near 1.0) at the specular peak. A threshold of 0.9 means "only pixels with NdotH > 0.9 get specular" — a small highlight. A threshold of 0.5 means "everything above 0.5" — a large highlight. size = 0.1 → threshold = 0.9 (small), size = 0.5 → threshold = 0.5 (large). The inversion makes the slider intuitive: bigger number = bigger highlight.

Rim Lighting: The Fresnel Edge

Rim lighting uses the same threshold-smoothstep pattern, but with a different input: how much the surface faces away from the camera (not the light):

// Rim lighting (additive): threshold-smoothstep on Fresnel
if (rim_enabled) {
    float fresnel = pow(1.0 - clamp(dot(NORMAL, VIEW), 0.0, 1.0), rim_size);
    float rim_edge = max(rim_smoothness, 0.001);
    float rim_mask = smoothstep(0.5 - rim_edge, 0.5 + rim_edge, fresnel);
    toon_color += rim_color.rgb * rim_mask * rim_intensity;
}

The mechanism:

  1. Fresnel: 1.0 - dot(NORMAL, VIEW) — 0 when facing camera directly, 1 at glancing angles (edges). This is the view-dependent "edge detection" signal.
  2. Power curve: pow(fresnel, rim_size) — the exponent controls how thin the rim is. Higher values concentrate the effect at extreme edges. rim_size = 2 = medium rim, rim_size = 5 = very thin edge line.
  3. Threshold-smoothstep: Same pattern as specular, applied to the powered fresnel value. The threshold at 0.5 means "the rim appears where fresnel × power exceeds 50%."
  4. Additive: Like specular, rim adds on top of the existing toon color.
Size semantics are inverted: For specular, bigger flat_specular_size = bigger highlight. For rim, bigger rim_size = thinner rim (because it's a power exponent, not a linear size). This is a common source of confusion — remember: specular size is "how much to include," rim size is "how aggressively to concentrate."

Why Additive (Not Multiplicative)

Both specular and rim use += to add their contribution on top of the diffuse toon color. Compare to Gooch shading from Lesson 10, which multiplies the albedo. The difference reflects what each effect represents physically:

  • Gooch (multiplicative): modifies the surface's own color — the material is tinted cool in shadow. It changes what's already there.
  • Specular/Rim (additive): adds extra light on top of the surface — the material receives additional energy at highlight points. It contributes new brightness.

This additive approach means specular and rim can push the final color above the maximum of the diffuse toon shading — which is exactly what highlights should do. They're brighter than the brightest diffuse band.

Same Pattern, Different Inputs

The two effects are structurally identical — the only difference is what feeds into the threshold-smoothstep:

AspectFlat SpecularRim Lighting
Input signalNdotH (half-vector, Blinn-Phong)1.0 - NdotV (Fresnel)
Depends onLight direction + view directionView direction only
Moves withLight source (rotate light → highlight moves)Camera (orbit camera → rim moves)
Size meaningBigger = larger highlight (linear inclusion)Bigger = thinner rim (power exponent)
Typical defaultsize=0.1, edge=0.0 (small, hard)size=2.0, smoothness=0.5 (medium, soft)
Use caseEye-catch, metallic gleam, wet surfacesCharacter separation, backlit halo, magical glow

Once you internalize the threshold-smoothstep pattern, you can create any binary shader effect with controllable edges: dissolve borders, fog distance, outline falloff, color zone masking — all the same math with different input signals.

Notice how specular moves when you rotate the light, but rim moves when you orbit the camera. They respond to different geometric relationships.

Alternative — lit-side-only rim: The MKToon reference shader applies rim everywhere (lit and shadowed faces both glow). Some styles prefer rim only on the lit side — like a backlit halo. To achieve this, multiply rim_mask by lit_factor before adding. This masks the rim so it only appears where diffuse lighting is strong. We use the simpler "everywhere" version here; the lit-side variant is one line to add if your art style needs it.

The Complete Shader

The full shader with all previous features (banding, Gooch, wrap, noise) plus the two new highlight systems. The specular and rim blocks sit at the end of light(), after the diffuse toon_color is computed:

shader_type spatial;
render_mode specular_disabled;

// === Albedo ===
uniform vec4 albedo_color : source_color = vec4(1.0);
uniform sampler2D albedo_texture : source_color;
uniform bool use_albedo_texture = false;

// === Toon Banding Controls ===
uniform float light_bands : hint_range(1, 9, 1) = 4.0;
uniform float light_bands_scale : hint_range(0, 1) = 0.5;
uniform float light_threshold : hint_range(0, 1) = 0.5;
uniform float diffuse_threshold_offset : hint_range(-1, 1) = 0.0;
uniform float diffuse_smoothness : hint_range(0, 1) = 0.0;

// === Wrapped Lighting ===
uniform float wrapped_lighting : hint_range(0, 1) = 1.0;
uniform float wrapped_lighting_scale : hint_range(0, 1) = 0.35;

// === Noise Map ===
uniform bool use_noise_map = false;
uniform sampler2D noise_map;
uniform float noise_strength : hint_range(0.0, 0.25) = 0.04;
uniform float noise_scale : hint_range(0.1, 10.0) = 1.0;

// === Gooch Shading ===
uniform vec4 gooch_bright_color : source_color = vec4(1.0);
uniform vec4 gooch_dark_color : source_color = vec4(0.2, 0.25, 0.35, 1.0);
uniform float gooch_ramp_intensity : hint_range(0, 1) = 0.5;

// === Flat Specular ===
uniform bool specular_enabled = false;
uniform vec4 flat_specular_color : source_color = vec4(1.0);
uniform float flat_specular_size : hint_range(0.0, 1.0) = 0.1;
uniform float flat_specular_edge_smoothness : hint_range(0.0, 1.0) = 0.0;
uniform float specular_intensity : hint_range(0.0, 2.0) = 1.0;

// === Rim Lighting ===
uniform bool rim_enabled = false;
uniform vec4 rim_color : source_color = vec4(1.0);
uniform float rim_size : hint_range(0.5, 8.0) = 2.0;
uniform float rim_smoothness : hint_range(0.0, 1.0) = 0.5;
uniform float rim_intensity : hint_range(0.0, 2.0) = 1.0;

void fragment() {
    vec3 col = albedo_color.rgb;
    if (use_albedo_texture) {
        col *= texture(albedo_texture, UV).rgb;
    }
    ALBEDO = col;
}

void light() {
    float NdotL = clamp(dot(NORMAL, LIGHT), 0.0, 1.0);

    // Wrapped lighting
    float wrap = clamp(wrapped_lighting * wrapped_lighting_scale, 0.0, 1.0);
    float wrapped = NdotL * (1.0 - wrap) + wrap;

    // Noise bias
    float noise_bias = 0.0;
    if (use_noise_map) {
        noise_bias = (texture(noise_map, UV * noise_scale).r - 0.5) * noise_strength;
    }

    // Centering
    float centered = clamp(wrapped - light_threshold - diffuse_threshold_offset + 0.5 + noise_bias, 0.0, 1.0);

    // Band quantization
    float banded = floor(centered * light_bands) / max(light_bands - 1.0, 1.0);

    // Smoothness blend
    float lit_factor = mix(banded, centered, diffuse_smoothness);

    // Scale
    lit_factor = 0.5 + (lit_factor - 0.5) * light_bands_scale;

    // Gooch shading
    vec3 shadow_tint = mix(ALBEDO, ALBEDO * gooch_dark_color.rgb, gooch_ramp_intensity);
    vec3 lit_tint = mix(ALBEDO, ALBEDO * gooch_bright_color.rgb, gooch_ramp_intensity);
    vec3 toon_color = mix(shadow_tint, lit_tint, lit_factor);

    // Flat specular (additive): threshold-smoothstep on Blinn-Phong half-vector
    if (specular_enabled) {
        vec3 half_dir = normalize(LIGHT + VIEW);
        float NdotH = clamp(dot(NORMAL, half_dir), 0.0, 1.0);
        float spec_threshold = 1.0 - flat_specular_size;
        float spec_edge = max(flat_specular_edge_smoothness, 0.001);
        float spec_mask = smoothstep(spec_threshold - spec_edge, spec_threshold + spec_edge, NdotH);
        toon_color += flat_specular_color.rgb * spec_mask * specular_intensity;
    }

    // Rim lighting (additive): threshold-smoothstep on Fresnel
    if (rim_enabled) {
        float fresnel = pow(1.0 - clamp(dot(NORMAL, VIEW), 0.0, 1.0), rim_size);
        float rim_edge = max(rim_smoothness, 0.001);
        float rim_mask = smoothstep(0.5 - rim_edge, 0.5 + rim_edge, fresnel);
        toon_color += rim_color.rgb * rim_mask * rim_intensity;
    }

    DIFFUSE_LIGHT = max(DIFFUSE_LIGHT, toon_color * LIGHT_COLOR * ATTENUATION);
}

Check Your Understanding

Exercise: A colleague adds flat specular with flat_specular_size = 0.9 expecting a large highlight covering most of the lit surface. Instead they get a tiny dot barely visible at the specular peak. They try flat_specular_size = 0.05 and get a huge bright area. "The size slider is backwards!" they say. Explain what's happening and what value gives a medium anime-style highlight.

Hint

Look at the threshold formula: spec_threshold = 1.0 - flat_specular_size. What threshold does size=0.9 produce? How much of the NdotH range passes that threshold?

Answer

The formula is spec_threshold = 1.0 - size. With size=0.9: threshold = 0.1 — meaning ANY pixel with NdotH > 0.1 gets specular. That's nearly the entire surface (huge highlight). With size=0.05: threshold = 0.95 — only pixels with NdotH > 0.95 pass (tiny dot at the exact reflection peak).

Wait — that's the opposite of what the colleague reports! Re-read: size=0.9 gives threshold=0.1 = huge. Size=0.05 gives threshold=0.95 = tiny. The slider IS intuitive: bigger size = bigger highlight. The colleague likely confused which value they entered, or their mesh's normals are producing unexpected NdotH values.

For a medium anime-style highlight: size = 0.1–0.2 (threshold 0.8–0.9). This produces a discrete stamp at the highlight peak without overwhelming the surface. Set edge_smoothness = 0.0 for the classic hard-edged anime look, or 0.1–0.2 for a slightly feathered metallic gleam.
