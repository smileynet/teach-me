Nodes & Scenes

Reference · Companion to Lesson 1

Core Concept

Everything in Godot is a tree of nodes. Save a tree to disk and it's a reusable scene. Compose simple scenes to build complex objects — don't inherit.

Lifecycle Order

CallbackWhenUse for
_ready()Once (children ready)Init, references, signal connections
_process(delta)Every frameVisuals, input, non-physics
_physics_process(delta)Fixed tick (60/s)Movement, collision, raycasts

Communication Rule

  • Signal up: children emit signals (don't know who listens)
  • Call down: parents call $Child.method()
  • Never: siblings talk directly (ancestor mediates)

Decision Aid

"How should these two nodes communicate?"

  • Child notifying parent → signal
  • Parent telling child what to do → direct method call
  • Two siblings need to interact → both signal to common ancestor
  • Any node needs a global service → autoload singleton

"Should I make a new scene?"

  • Used more than once → yes
  • Logically independent unit → yes
  • Getting too complex to edit → yes, split it
  • Only used in one place, 2-3 nodes → keep inline
