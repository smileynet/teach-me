OIDC Auth Flows

Reference · Companion to Lesson 1

Core Concept

User authenticates at the IdP, your app gets a signed proof of identity. Your app never sees the user's password. The authorization code flow keeps tokens off the browser entirely — exchanged server-to-server.

The Flow (8 Steps)

  1. User clicks "Login" → your app builds the auth URL
  2. Redirect to IdP (with client_id, scope=openid, state, code_challenge)
  3. User authenticates at IdP (enters credentials)
  4. IdP redirects back with ?code=xxx&state=yyy
  5. Browser hits your callback endpoint
  6. Your server POSTs code + code_verifier to token endpoint
  7. IdP returns {id_token, access_token, refresh_token}
  8. Validate ID token → user is logged in

What Your Rust Code Does at Each Step

StepCode responsibility
1-2Generate state + nonce + code_verifier. Build URL. Store state/nonce in session. Return 302.
5Callback handler: verify state matches stored value
6POST to token_endpoint: code, redirect_uri, client_id, code_verifier
7-8Parse response, validate ID token (signature + claims)

PKCE (Proof Key for Code Exchange)

StepWhat
Before authcode_verifier = 43-128 random URL-safe chars
Computecode_challenge = BASE64URL(SHA256(code_verifier))
Auth requestSend code_challenge + code_challenge_method=S256
Token exchangeSend code_verifier (the original)
Server checksHash verifier → compare to stored challenge

Why: An interceptor who captures the code from the redirect can't exchange it without the code_verifier (never sent via browser).

Discovery

All provider URLs come from one endpoint:

GET https://<issuer>/.well-known/openid-configuration

Returns: authorization_endpoint, token_endpoint, jwks_uri, supported scopes/algorithms.

Rust:

CoreProviderMetadata::discover_async(issuer_url, http_client).await?

Quick Decision

  • Web app login? → Authorization Code + PKCE (always)
  • Native/CLI app? → Authorization Code + PKCE + localhost redirect
  • API validating tokens? → You don't do the flow — just validate incoming tokens (Lesson 2)
  • Implicit flow? → Deprecated. Don't use it.
