# Resources

## Primary sources

| Resource | Type | Trust | Notes |
|----------|------|-------|-------|
| [Rust Roguelike Tutorial (bfnightly)](https://bfnightly.bracketproductions.com/) | Book/tutorial | High | Herbert Wolverson's complete roguelike in Rust using bracket-lib. The canonical resource. |
| [Roguelike Tutorial Revised (thebracket)](https://github.com/amethyst/rustrogueliketutorial) | Source code | High | Full source for the above — reference implementation |
| [RogueBasin: Complete Roguelike Tutorial](http://www.roguebasin.com/index.php/Complete_Roguelike_Tutorial,_using_python%2Blibtcod) | Tutorial | Medium | Python but concepts transfer — procgen algorithms, FOV, AI patterns |
| [ECS FAQ (Rust gamedev)](https://arewegameyet.rs/ecosystem/ecs/) | Reference | High | ECS library comparison for Rust (specs, legion, hecs, bevy_ecs) |
| [Bob Nystrom — Game Programming Patterns](https://gameprogrammingpatterns.com/) | Book | High | Language-agnostic architecture patterns (game loop, component, observer) |
| [Procedural Generation in Game Design (Short & Adams)](https://www.amazon.com/Procedural-Generation-Design-Tanya-Short/dp/1498799191) | Book | High | Academic but practical — PCG theory and case studies |
