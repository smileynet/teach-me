# Workout Fundamentals

## Orientation

Strength training is governed by a small number of principles that explain 90% of results. You'll learn the mechanism behind all adaptation (progressive overload), why rest is when gains actually happen (recovery), and how to structure a simple program that applies these principles (programming). Everything else — specific exercises, supplements, timing tricks — is implementation detail that matters far less than getting these fundamentals right.
