Quiz: Iceberg Metadata Tree

Test your understanding of Lesson 1.

What problem does Iceberg's manifest file solve?

Eliminates the need to list S3 directories by tracking files with column-level statistics
Stores the table schema and partition specifications for downstream consumers
Controls which users can access specific partitions of the data lake
Compresses data files to reduce storage costs in the S3 data layer

What makes Iceberg writes atomic (all-or-nothing)?

The catalog locks the table during writes preventing any concurrent access
Data files are written to a staging area and moved atomically to the final path
The catalog pointer to the current metadata file is updated as a single atomic operation
S3's built-in transaction support ensures all files appear simultaneously to readers

Why can Iceberg evolve partition schemes without rewriting existing data?

Old data is automatically repartitioned in the background by a compaction process
Partition spec history is stored in metadata — the engine handles translation at query time
The catalog maintains a separate partition mapping table that's updated independently
Partition schemes are applied only at query time so the physical layout never changes
