First Import — The Happy Path

Lesson 1 · Godot Asset Pipeline · ~4 min read
Win: You can import a 3D model into Godot and see it render in a scene.
After this lesson: you can get a 3D model into Godot and see it appear on screen — the whole pipeline once, minimally.

Get one model into Godot and see it render

The whole 3D asset pipeline — formats, collision, level-of-detail, rigging — starts with one small act: putting a single model into Godot and seeing it appear. This lesson does exactly that, once, with no decisions to make. You will import a chair and watch it show up in a scene. Everything harder builds on this one success.

We are using a ready-made chair (a Kenney model, free to use). You do not need Blender or any modeling skill — the model already exists as a .glb file. Later lessons cover where that file comes from and how to choose formats; here, you just bring it in.

Step 1 — put the file under res://

A Godot project is a folder. Everything inside it lives under the res:// path. To hand Godot a model, you copy the file into that folder — drag chair.glb into your project's file list, or drop it in the folder on disk. That is the entire "give Godot the model" step. There is no import button to press.

Step 2 — Godot imports it automatically

The moment the file lands under res://, Godot imports it: it reads the file, converts it into its own internal scene format, and shows it in the FileSystem dock. Your original chair.glb is never modified — Godot works from a copy. Nothing appears in your game yet; the chair is now something Godot knows about, sitting in the file list, waiting to be used.

The one thing to remember: importing a model is not the same as putting it in your scene. Import makes Godot aware of the model. It shows up in the file list — not in your game — until you take the next step.

Step 3 — drag it into the scene to see it

Open a 3D scene (one with a camera and a light, so there is something to see it with). Drag the imported chair.glb from the FileSystem dock into the scene tree. This creates an instance of the model — it appears as a single node in your scene, and the chair shows up in the viewport, lit and textured. That is the win: a model authored elsewhere, now rendering in your Godot scene.

That is the complete happy path. You imported a model and it works. What you did not do — choose between file formats, add collision, worry about what to commit to version control — is what the rest of this track is about. Each of those is a harder version of a step you just took once.

Check Your Understanding

You drag chair.glb into your project. It shows up in the FileSystem dock, but when you press Play, the chair is nowhere in your scene. Nothing errored. What is the one step you still need to do?

Hint

Look at the difference between the file list and the scene tree. Which one is the chair in, and which one does your running game actually render?

Answer

Importing only put the chair in the FileSystem dock — Godot knows about it, but it is not in any scene. You need to drag the imported model from the FileSystem dock into the scene tree, which creates an instance of it. Import ≠ instance: the first makes Godot aware of the model; the second is what actually places it in your game so it renders.
