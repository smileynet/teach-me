Godot Asset Pipeline — Getting 3D In and Out of Godot

This track teaches Godot's side of the 3D asset pipeline: how a model authored in a DCC tool (Blender, etc.) becomes a running, correct Godot scene — and, when needed, how it comes back out. It is deliberately Godot-import-*mechanics*-specific: the glTF standard itself (anatomy, the export spec, skins) lives in the engine-agnostic `gltf-format` track, which this one consumes. The track is built happy-path-first: topic 1 is the pure win — one model in, rendered, zero decisions — and every later topic takes that standing win and widens it to one harder case (formats, version control, collision, performance, rigging, round-trip), always landing back at a working result. Assets are CC0 (Kenney); the source→glTF path is real end-to-end via the `make-blend` / `export-godot-glb` tools.
