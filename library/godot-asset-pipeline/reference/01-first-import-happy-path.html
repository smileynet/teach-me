First Import — The Happy Path — Quick Reference

Reference · Godot Asset Pipeline
Pull this up when you need a quick lookup.

The happy path, in four moves

  1. Have a model file — e.g. chair.glb.
  2. Copy it under res:// — anywhere in the project folder. No button.
  3. Godot auto-imports — converts to its own format, shows it in the FileSystem dock. Your source is untouched.
  4. Drag it into the scene tree — creates an instance; the model renders.

The trap: import ≠ instance

Importing puts the model in the file list. It is not in your game until you instance it by dragging it into a scene's node tree. "It's in the FileSystem dock but not in my scene" means: import succeeded, you have not instanced it yet.

Terms

  • Import — one-way conversion of a source file into Godot's internal format (a copy; source never edited).
  • Instance — a placed copy of an imported scene in a node tree; this is what renders.
  • res:// — the project folder; dropping a file here triggers auto-import.
  • FileSystem dock — the panel listing everything under res://.
