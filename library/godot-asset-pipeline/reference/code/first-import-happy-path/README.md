# first-import-happy-path — code files

Downloadable artifacts for godot-asset-pipeline topic 1. All CC0.

| File | What it is |
|------|------------|
| `chair.glb` | The neutral prop you import in this lesson — a single-mesh Kenney chair, exported Godot-ready (glTF 2.0, +Y-up, no lights/cameras). Drop it into a Godot project's `res://` and drag it into the scene tree. |
| `License.txt` | Kenney Furniture Kit license (CC0 1.0). |

The editable Blender source is at `../../blender/chair.blend` (derived from Kenney's `.glb` via
`mise run make-blend`; re-export with `mise run export-godot-glb`).

**Credit:** 3D chair by [Kenney](https://kenney.nl) (Furniture Kit) — CC0 1.0.
